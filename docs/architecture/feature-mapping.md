# AndroCAD Feature-to-OCCT API Mapping Specification

This specification documents the exact C++ Open CASCADE Technology (OCCT) APIs, topological preconditions, and error-handling strategies for all parametric features supported by AndroCAD.

---

## 1. Feature Mapping Table

| Feature Name | Primary OCCT API Class | Inputs & Parameter Types | Generated Output Topology | Edge Cases & Robustness Boundaries | Failure Recovery Strategy |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Extrude (Pad)** | `BRepPrimAPI_MakePrism` | `TopoDS_Face` profile,<br>`gp_Vec` direction & distance | `TopoDS_Shape` (Solid) | - Self-intersecting profile wire.<br>- Zero-length direction vector.<br>- Non-planar profile. | Validate with `BRepCheck_Analyzer`. Throw C++ exception if invalid before calling `MakePrism`. Check `IsDone()`. |
| **Revolve** | `BRepPrimAPI_MakeRevol` | `TopoDS_Face` profile,<br>`gp_Ax1` revolution axis,<br>`Standard_Real` angle $\in (0, 2\pi]$ | `TopoDS_Shape` (Solid) | - Profile crosses revolution axis (self-intersection).<br>- Angle $\le 0$ or $> 2\pi$. | Pre-check profile 2D bounding box and 2D intersection against the axis. Abort if axis penetrates profile interior. |
| **Fillet** | `BRepFilletAPI_MakeFillet` | `TopoDS_Shape` input solid,<br>`std::vector<TopoDS_Edge>` target edges,<br>`Standard_Real` radius | `TopoDS_Shape` (Solid) | - Radius exceeds local face curvature.<br>- Non-tangent corner edge collisions throw `StdFail_NotDone`.<br>- Swallowing adjacent tiny edges. | Wrap in `try/catch(Standard_Failure)`. Verify `IsDone()`. If failed, revert to original unfilleted shape and flag feature error. |
| **Chamfer** | `BRepFilletAPI_MakeChamfer` | `TopoDS_Shape` input solid,<br>`std::vector<TopoDS_Edge>` target edges,<br>`TopoDS_Face` reference face,<br>`Standard_Real` distance / angle | `TopoDS_Shape` (Solid) | - Chamfer plane intersects adjacent features.<br>- Inverted reference face normal. | Verify `IsDone()`. Catch `Standard_Failure` gracefully. |
| **Combine: Join (Fuse)** | `BRepAlgoAPI_Fuse` | `TopoDS_Shape` tool,<br>`TopoDS_Shape` target solid | `TopoDS_Shape` (Solid) | - Coplanar coincident boundaries cause BOP failure.<br>- Non-manifold intersection. | Call `SetFuzzyValue(1e-5)` on `BRepAlgoAPI_Fuse` to resolve near-coincident boundaries. Check `IsDone()`. |
| **Combine: Cut** | `BRepAlgoAPI_Cut` | `TopoDS_Shape` target solid,<br>`TopoDS_Shape` cutting tool | `TopoDS_Shape` (Solid or Compound) | - Cutting tool completely misses target (null cut).<br>- Cut splits solid into disconnected lumps. | Check `HasDeleted()` and `HasGenerated()`. If multiple solids generated, preserve as connected multi-body or select primary solid based on user intent. |
| **Combine: Intersect** | `BRepAlgoAPI_Common` | `TopoDS_Shape` solid A,<br>`TopoDS_Shape` solid B | `TopoDS_Shape` (Solid) | - Disjoint solids yield empty shape. | Validate that output shape contains at least one `TopAbs_SOLID`. |
| **Shell (Hollow)** | `BRepOffsetAPI_MakeThickSolid` | `TopoDS_Shape` input solid,<br>`TopTools_ListOfShape` opening faces,<br>`Standard_Real` wall thickness | `TopoDS_Shape` (Solid) | - Offset distance exceeds concave surface radius of curvature.<br>- Shelling complex fillets causes topological collapse. | Recommend shelling prior to detail filleting. Check `IsDone()`. |
| **Hole (Simple / C-Bore / C-Sink)** | `BRepPrimAPI_MakePrism` or `BRepPrimAPI_MakeRevol` + `BRepAlgoAPI_Cut` | `gp_Pnt` position, `gp_Dir` axis,<br>diameter, depth,<br>optional counterbore/countersink dimensions | `TopoDS_Shape` (Solid) | - Hole axis not perpendicular to entry face.<br>- Blind hole depth penetrates through back wall creating paper-thin sheet. | Compute intersection bounds with target body. Differentiate "Distance" vs "Through All" semantics. |
| **Sweep** | `BRepOffsetAPI_MakePipeShell` | `TopoDS_Wire` spine,<br>`TopoDS_Face` profile | `TopoDS_Shape` (Solid) | - Spine curvature radius tighter than profile radius (self-intersection).<br>- Frenet frame twisting. | Sample spine curvature with `GCPnts_QuasiUniformDeflection`. Verify minimum radius of curvature $> \text{profile half-width}$. |
| **Loft** | `BRepOffsetAPI_ThruSections` | `std::vector<TopoDS_Wire>` section profiles | `TopoDS_Shape` (Solid) | - Different vertex counts or opposing wire directions cause twisted skin. | Pre-process wires: synchronize starting vertices and enforce identical counter-clockwise orientation. |
| **STEP Import** | `STEPControl_Reader` | `const char*` file path | `TopoDS_Shape` | - Non-manifold shells, open seams, invalid tolerances in foreign CAD file. | Run `ShapeFix_Shape` to heal sewing defects and orientation errors after `TransferRoots()`. |
| **STEP Export** | `STEPControl_Writer` | `TopoDS_Shape` input,<br>`const char*` output path | AP214 / AP242 STEP file | - Unassigned colors / layer metadata. | Configure `write.step.schema` to AP214. Check return status `IFSelect_RetDone`. |
| **STL Export** | `StlAPI_Writer` | `TopoDS_Shape` input,<br>`const char*` output path,<br>binary mode flag | Binary STL file | - High polygon count causing memory exhaustion.<br>- Coarse deflection producing faceted surfaces. | Generate mesh via `BRepMesh_IncrementalMesh` with user-selected linear and angular deflection prior to writing binary STL. |
| **STL Import** | `RWStl::ReadFile` | `const char*` file path | `Poly_Triangulation` / `TopoDS_Face` | - Degenerate zero-area triangles in mesh. | Read mesh into `Poly_Triangulation` for direct GPU rendering. Convert to B-Rep face only if explicit mesh-to-solid conversion is requested. |
